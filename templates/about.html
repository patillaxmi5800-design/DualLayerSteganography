🛡 Dual Layer Security

StegoSecure is a Dual Layer Steganography application designed to protect confidential information. The system combines AES Encryption with LSB Steganography. The secret message is first encrypted and then hidden inside a digital image. Only a user with the correct AES key can recover the original secret message.

🔐

AES

Provides encryption for the secret message.

🖼

LSB

Hides encrypted data inside image pixels.
